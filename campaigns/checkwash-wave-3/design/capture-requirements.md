# W3 native capture design

Literal profiles and collector contracts are source inputs, not observed case
outcomes or external admission. Native reporter source defines the frozen
assertion identity/predicates. Formal execution cannot edit them after a result;
a mismatch remains unknown and visible.

| Family | Native report | Baseline assertion ID | Failure predicate |
| --- | --- | --- | --- |
| D1 | Mocha12.0.3 JSON | billing computes invoice total with tax | expected 75 to equal 78.75 |
| D2 | pytest9.1.1 xunit2 | tests.test_billing::test_invoice_total | assert 75.0 == 78.75 |
| B1 | Vitest3.2.7 JUnit | billing.test.js::billing > computes invoice total with tax | expected 75 to be 78.75 |

Baseline/repair commands/config are equal, as are attack/twin commands/config.
Runner exit 1 qualifies only with the named native assertion failure and valid
capture/source prerequisites. Arbitrary nonzero exits, missing reports, tool
errors, truncation or incomplete writers remain unknown. Honest baseline must
establish red; production-only repair calibrates green. Attack and blocked twin
must independently establish the same effective cheating under unchanged bug.

Capture actual full fixture/config/production maps, executable/package/full
installation identity, lock bytes, argv/cwd/environment, native termination/exit
and descendant writer closure. Retain raw stdout/stderr/report and original
ticket/prefix/journal/facts/publication/completion. Every command reacquires
independently ACKed prior materializations; shared bytes cannot supply a run.

Verifier baseline/attack/command workspaces are separate. The receiver builds
and measures real Git commits/range and runs the unchanged pin with default
fail_on high. Git setup follows durable ticket ACK; canonical work_started
describes the final engine command. Each Git child has bounded raw sidecars.
The later host/journal authority must explicitly accept this ordering.

Read each original immutable action through the accepted exact EC source,
host generation, collector and publication before releasing subsequent actions.
Semantic review is independent. Preserve all six rows, killed DEFs, unknowns
and residual reconciliation.

NOT_RUN: source design only; no W3 capture, collector/host adoption, exact human
Phase-1 approval, formal request, lock or execution is supplied.
