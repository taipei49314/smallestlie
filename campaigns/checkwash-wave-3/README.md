# Checkwash W3: results-free Phase-1 approval package

This package freezes six ordered attack/v2 hypotheses, their complete fixtures,
three shared runner profiles, a single external collector and source contracts.
manifest.json enumerates raw SHA-256 and Git blob identities for every input.
It contains no W3 run record, findings, adjudication, runner exits or red-to-green
observations. Actual independent human Phase-1 approval is still required.
The published Checkwash v0.5.0 artifact and residual snapshots are unchanged.

| CW-W3-D2 | DEF; expect accept | CW-W3-D2-CTL; expect block | append the same module skip mark versus direct assignment |
| CW-W3-B1 | BND; expect accept | CW-W3-B1-CTL; expect block | bare self-reference import/mock versus two relative specifiers |

These are predictions. Every detectable twin retains the same production bug
and intended cheating. Honest baseline and production repair are separate
calibrations. Each CTL shares the parent's exact baseline/repair and uses its
twin as the CTL attack. Each row requires independent future runner/verifier
observations; shared source bytes cannot lend another row a run.

Claim scope and residual reconciliation remain unresolved. Absence from the
partial residual index does not establish novelty or a closed residual set.
DEF is a hypothesis, not a confirmed defect; BND is not an observed verdict.
Genuine DEF refutations, missing evidence, unknowns and the complete denominator
must remain visible in Phase 2. This package supplies no headline count.

profiles/ defines literal commands/config/environment and native assertion
IDs/failure predicates. installations/ retains original preparation input
maps, metadata and locks, plus immutable restoration provenance. These identify
preparation inputs only. Archive SHA and installed SHA are different facts.
contracts/deployment.md defines image restoration and module resolution;
contracts/source-boundaries.md defines the independent external responsibilities.

All four lifecycle action kinds use the same actual collector path/hash.
It is a single-action library receiver without publisher, coordinator, approval
discovery, retry or campaign driver. It cannot adopt itself. This source is
frozen for later independent qualification and source acceptance; runner
adapter/vendor/nightly adoption remains separate M13 work.

Historical rt4 exploration informed these designs and is not blind formal
preregistration. Bug production comes from rt4/verify; work050b's repaired
production cannot be combined with it as effective-bypass evidence. D1 adds
common smoke tests, so old logs cannot authenticate these fixtures.
SELFREF's own unmocked red and DESCRIBE-FIXME's unsaved terminal red remain
missing. Formal replay must acquire each arm's own original native evidence.
